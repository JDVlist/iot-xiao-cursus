# What Is Arduino?

![Arduino316](https://github.com/user-attachments/assets/8df9108e-2fce-4fc7-b660-835722d35bab)

- Originally created for art installations
- Simple computer
- Standard way to program in C

## Technical Specifications

- 32KB flash memory
- 2KB SRAM
- 1KB EEPROM
- 16 MHz clock speed
- 14 digital I/O pins (6 analog)
- **5V** I/O standard
